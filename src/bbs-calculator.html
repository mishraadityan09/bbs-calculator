Help — how every number works (tap to open)

Cutting length method
Cutting length = shape length + hooks − bend deductions + laps, then rounded UP to the next 25 mm (IS 2502 Cl. 5.1.1 — toggle in Settings).
• Shape length = sum of outer dimensions A/B/C/D for the chosen shape (formulas listed under "Shape library" below).
• Hooks: each hook adds hook factor × dia, minimum the hook floor. Default 10d ≥ 75 mm = legacy seismic 135° hook (IS 13920:1993 / common bridge practice). IS 13920:2016 allows 6d ≥ 65 mm; non-seismic 90° stirrup hook is 8d — change the factor in Settings if your spec says so.
• Bend deductions (because outer dimensions overlap at each corner): 45°→1d, 90°→2d, 135°→3d, 180°→4d (SP-34 site convention, sharp-edge method). Each shape applies its own bend counts automatically; the Custom shape lets you set them by hand.
• Laps: leave the Laps cell blank and the tool auto-inserts laps when the bar is longer than the stock length: pieces = 1 + ⌈(L − stock)/(stock − lap)⌉. Auto values show with a *. Type a number to override. Lap length = lap factor × dia.
Lap factors for THIS project (35d / 50d) and IRC:112
Drawing note 6 says lap = 35d, and 50d for bar mark 1 (top bars). This matches IRC:112-2020 exactly: for Fe500D in M60, basic anchorage k = 25 (Table 15.4); with 50% bars lapped at a section ×1.4 → 35d (favourable bond); top bars of a deep pour are "unfavourable bond" ×1.43 → ≈50d. So use 50 in the Lap×dia cell for top bars, 35 for the rest — already prefilled.
Bars over 32 mm must not be lap-spliced (IRC:112 Cl. 15.2.6) — the tool warns and you should use couplers (set Laps = 0 and note "couplers" in Remarks; couplers add no length).
Payable weight vs procurement weight (MoRTH billing)
MoRTH Specification Cl. 1608: reinforcement is paid by measured length including hooks but EXCLUDING laps, converted to tonnes at nominal mass. Wastage, laps, couplers, chairs and binding wire are NOT paid — they are inside the rate.
• Payable weight (green card) = cutting length minus lap lengths × count × unit mass. Use this for BOQ/billing.
• Procurement weight (blue card) = full cutting length incl. laps × count × unit mass, plus the wastage % and rolling-margin % from Settings. Use this for ordering steel.
Rolling margin: steel is billed between supplier and contractor on actual section weight; IS 1786 allows ±3% (bars >16 mm), ±5% (12–16), ±7% (≤10). Enter your measured margin % (negative = rolls light) to adjust the procurement tonnage.
Unit weight
Default uses the IS 1786 Table 1 nominal masses (8:0.395, 10:0.617, 12:0.885, 16:1.58, 20:2.47, 25:3.85, 28:4.83, 32:6.31, 36:7.99, 40:9.86 kg/m) — the values billing must use. Untick the toggle to fall back to d²/162 for odd diameters.
Shape library formulas
Straight: A · L-bend: A+B (1×90°) · U / end-bends: A+B+C (2×90°) · Crank/bent-up: A + 2×0.42D (4×45°, the 0.42D rule) · Closed 2-leg stirrup: 2(A+B) + 2 hooks (3×90° + 2×135°) · Circular ring: πD + 2 hooks (2×135°) · Spiral/helix: n×√((πD)² + P²) + 2πD closing turns, n = ⌈H/P⌉+1 · Chair: A+2B+2C (4×90°) · Custom: comma-separated segment lengths + your own bend counts.
For stirrups measure A, B out-to-out: member size − 2×cover (this cap: 3400−90=3310, 2500−90=2410 at the pier).
Bars are counted as members × (⌈run ÷ spacing⌉ + 1) when Spacing and Run are filled; otherwise members × bars/member typed directly.
Cutting plan (steel ordering)
The optimizer packs every cut piece (per diameter) into stock bars using first-fit-decreasing — the same heuristic commercial cut-and-bend software uses, typically within 1–3% of the mathematical optimum. Offcuts longer than the reuse threshold are counted reusable, not waste. Bars longer than stock are split at laps automatically before nesting.

📘 Guide — how to use & make changes (no coding needed)

First time / checking the P355 numbers
1. Every white cell was read from drawing SPS-P355-VIA-SD; every yellow cell is an assumption — fix those first.
2. From sheet 10 plan, find the stirrup zone lengths: type each zone's length into the Run cell of bars 5 / 5a — the bar count then computes itself from the @175 spacing (the Bars/mem cell locks automatically when Run + Spacing are filled).
3. From Section C-C, count/measure the 5a internal link widths and replace the assumed 300 in dimension A.
4. Side bars 3 / 3a: enter each zone depth in Run (spacing 135 is already set, Members = 2 faces).
5. Add the missing bars (3b, 4, 4a, M1/M2 mesh) with + Add bar when you have sheets 7–11.
Changing a rule (lap, hook, wastage, rate…)
• All rules live in Settings — hover a label to read what it controls. Nothing is hidden in code.
• Per-bar lap rule: the Lap ×dia cell on each row (50 for top mark 1, 35 for others, per drawing note 6).
• Project-specific hook rule? Change Hook length ×dia (10 → 6 for IS 13920:2016, 8 for non-seismic 90° hooks).
• Steel price: put your rate in ₹/kg and the procurement card shows cost.
• Different structure entirely? Change the Project header, delete rows, add your own — the engine is generic.
Saving, sharing and printing
• The tool autosaves in this browser — close and reopen, your data is there. (Clearing browser data erases it!)
• ⬇ Save project file downloads a .json you can WhatsApp to anyone — they open this same HTML and use ⬆ Load project file. That's how we exchange updates without touching code.
• ⬇ CSV opens directly in Excel for billing sheets.
• 🖨 Print BBS sheet prints the formal A4-landscape schedule with shape sketches, dia-wise summary, payable vs procurement totals and signature blocks — that's the page to submit for checking.
• ↺ Reset brings back the original P355 drawing data if anything gets messed up.
Reading the results
• Cut len = one bar's cutting length in mm (already rounded up to 25 mm). Weight includes laps (what you buy); Payable excludes laps (what MoRTH pays).
• Laps shown with * were inserted automatically because the bar is longer than 12 m stock.
• ⚠ marks a problem — hover it to read (e.g. lap on a >32 mm bar, bar longer than stock with laps forced to 0).
• The Cutting plan at the bottom says exactly how many 12 m bars to order per diameter and how to cut each one.
